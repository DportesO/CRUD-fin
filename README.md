# FinControl

Trabalho Interdisciplinar (TIAW) do curso de Análise e Desenvolvimento de Sistemas da PUC Minas.
Sistema web de controle financeiro pessoal voltado para jovens de 15 a 29 anos.

## Funcionalidades da Sprint 1

- Landing page com a apresentação da solução
- Cadastro de usuário
- Login e logout
- Cadastro, edição e exclusão de receitas e despesas
- Resumo com total de receitas, total de despesas e saldo

## Estrutura de pastas

```
assets/
  css/     arquivos de estilo separados por área da página
  img/     imagens e logo
  js/      funcionalidades do sistema
index.html        landing page
cadastro.html     criar conta
login.html        entrar no sistema
lancamentos.html  painel de lançamentos
```

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Crie uma conta, faça o login e cadastre seus lançamentos.

Os dados são armazenados no `localStorage` do navegador, portanto ficam salvos
apenas no computador em que foram cadastrados.
